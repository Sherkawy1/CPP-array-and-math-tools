\# Basic C++ Array Processing \& Math Utilities



An interactive, modular C++ console application that demonstrates basic algorithm implementation, array manipulation, and dynamic mathematical analysis.



\## 📌 Features



\- \*\*Array Statistics\*\*: Calculates the sum, average, count, minimum, and maximum values for both odd and even numbers in a given array.

\- \*\*Linear Search\*\*: Checks if a specific element exists within the array and returns its zero-based index.

\- \*\*Prime Number Checker\*\*: Evaluates whether a given integer is a prime number.

\- \*\*Factorial Calculation\*\*: Uses recursion to compute the factorial of a given positive integer.
